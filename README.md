## 💡 How to Run Locally

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Python 3.8+ (for resume generation)
- Git installed on your system

### Installation Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/bidishajoshi/bidishasportfolio.git
   cd bidishasportfolio
   ```

2. **Open in browser (frontend only):**
   ```bash
   # Simply open the file
   start index.html
   ```
   Or double-click `index.html` in your file explorer.

3. **Generate Resume (optional):**
   ```bash
   # Install required Python packages
   pip install reportlab

   # Run the resume generator
   python generate_resume.py
   
   # Resume will be generated as resume.pdf
   ```

4. **View the portfolio:**
   - Open in your browser at `http://localhost` or simply as a file
